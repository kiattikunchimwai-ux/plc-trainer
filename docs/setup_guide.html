คู่มือตั้งค่า GX Simulator3

สำหรับเชื่อมต่อกับโปรแกรม PLC Trainer ผ่าน SLMP · ทดสอบกับ GX Works3 เวอร์ชัน 1.110Q

สิ่งที่ต้องมี: GX Works3 (มี GX Simulator3 ติดมาด้วย) · โปรแกรม PLC Trainer · โปรเจกต์ ladder ตัวอย่าง gx_projects\test_r04.gx3 (ตั้งค่าตามคู่มือนี้ไว้แล้ว สามารถเปิดแล้วข้ามไปขั้นที่ 4 ได้เลย)

1เปิดโปรเจกต์และเปลี่ยนชนิด CPU เป็น R04

GX Simulator3 จะตอบ SLMP กับโปรแกรมภายนอก เฉพาะโปรเจกต์ RCPU (iQ-R) เท่านั้น ถ้าโปรเจกต์ของคุณเป็น FX5U ให้เปลี่ยนชนิด CPU ก่อน (ladder ที่เขียนไว้จะยังอยู่ครบ)

  1. ไปที่เมนู Project → Change Module Type/Operation Mode...
  2. ตั้ง Series = RCPU และ Type = R04 แล้วกด OK
  3. หน้าต่างยืนยันจะบอกว่าโปรแกรมและพารามิเตอร์จะถูกย้ายไปด้วย กด OK
  4. จากนั้นใช้ Project → Save As บันทึกเป็นไฟล์ใหม่ เช่น test_r04.gx3
💡 ถ้าเริ่มโปรเจกต์ใหม่ ให้เลือก Series = RCPU และ Type = R04 ตั้งแต่ตอน Project → New

2อนุญาตให้โปรแกรมภายนอกเขียนค่า (SLMP)

  1. ที่หน้าต่าง Navigation ไปที่ Parameter → R04CPU → Module Parameter แล้วดับเบิลคลิก
    (ถ้าไม่เห็น Navigation ให้ไปที่ View → Docking Window → Navigation)
  2. ในหัวข้อ Own Node Settings หาบรรทัด Enable/Disable Online Change
  3. เปลี่ยนจาก "Disable All (SLMP)" เป็น "Enable All (SLMP)" แล้วกด Apply ที่มุมขวาล่าง
⚠️ ถ้าไม่ตั้งค่านี้ PLC Trainer จะอ่านค่าได้ แต่กดปุ่ม X แล้วจะไม่มีผล

3Convert โปรแกรม

กด F4 (Convert) ถ้ามีคำถามว่า Rebuild All ให้กด Yes รอจนคำว่า Project ในหน้าต่าง Navigation ไม่เป็นสีแดงแล้ว

4เริ่ม Simulation

  1. ไปที่เมนู Debug → Simulation → Start Simulation
  2. รอให้หน้าต่าง Write to PLC ทำงานเสร็จ แล้วกด Close
  3. หน้าต่าง GX Simulator3 ต้องแสดง R04CPU สวิตช์อยู่ที่ RUN และไฟ P RUN เป็นสีเขียว
ℹ️ ถ้าไฟ ERROR เป็นสีแดงแต่ P RUN ยังเขียวอยู่ ladder ก็ยังทำงานได้ตามปกติ (จากการทดสอบ ส่วนสาเหตุของไฟ ERROR ยังไม่ได้ตรวจสอบ)

5(แนะนำ) เปิด Monitor ladder

ดับเบิลคลิก Program → Scan → MAIN → ProgPou → ProgramBody แล้วคลิกในหน้า ladder หนึ่งครั้งก่อนกด F3 (Start Monitoring) จะเห็นหน้าสัมผัส คอยล์ และค่า T/C เปลี่ยนตามจริงไปพร้อมกับ PLC Trainer

6เชื่อมต่อจาก PLC Trainer

  1. เปิดไอคอน PLC Trainer บน Desktop
  2. ที่แถบบน ช่อง PLC เลือก GX Simulator3 (SLMP) · ตั้ง Host 127.0.0.1, Port 5511 ที่ปุ่ม ⚙
  3. กด เชื่อมต่อ ไฟ ONLINE ที่มุมขวาล่างต้องเป็นสีเขียว
  4. โปรแกรมเปิดเป็นหน้าเปล่า: กด เปิด เลือก default.plcpanel แล้วที่แท็บผังอุปกรณ์ คลิกปุ่ม Start (X0) แล้วดูว่าหลอด Y0 ทั้งในโปรแกรมและใน GX Works3 ติดตามกัน
  5. ถ้าจะจัดผังเอง กด ✎ แก้ไขผัง แล้วลากอุปกรณ์จากแผงอุปกรณ์มาวาง จากนั้นตั้ง Address ในแผงคุณสมบัติ ให้ตรงกับ ladder ของคุณ
💡 iQ-R ใช้เลข X/Y ฐาน 16 ดังนั้นปุ่มที่ต่อกับ X8–XF ใช้ได้ (ช่อง Address จะเตือนถ้าพิมพ์เลขที่ไม่มีจริง)
